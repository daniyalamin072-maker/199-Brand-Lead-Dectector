# Local Lead Lantern

Build a high-contrast minimalist dashboard for an agency named '199-Brand'. Include input fields for City, Country, and Home-Service Niche (Plumbing, Roofing, HVAC). Add a 'Generate Leads' button, a metrics card showing total leads found, and a data table to display business name, phone number, address, and website status with a 'Copy Lead' button.
